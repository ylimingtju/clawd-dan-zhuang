# 第一轮角色造型审核图 · 生成记录

生成日期：2026-10-09
方法：Python 生成矢量 SVG → Chrome 无头模式渲染 PNG。未使用 AI 图像生成，也没有把照片贴到角色身上。

## 文件
- `clawd.py`：统一角色几何（身体、眼睛、手臂、腿、侧面阴影）、发型部件、绘图工具
- `looks.py`：13 套服装的图层，每套一个类（L01–L13），类名下的注释写明结构
- `render.py`：`python3 render.py <输出目录> [编号...]`，重新生成 SVG 与 PNG，可只重渲某几套，例如 `python3 render.py .. 7 9`
- `overview.py`：`python3 overview.py <输出目录>`，重新排版 00_造型审核总览.png
- `svg/`：每张图的可编辑矢量源文件，可用 Illustrator / Figma / Inkscape 打开局部修改
- `Clawd_基础角色.png`：未穿衣的基础比例参考

## 统一规格（全套共用，不随造型改变）
- 画布 1600×1600，背景 #ECE7E1
- 角色缩放 1.25，地面线 y=1215
- 身体正面 400×390，右侧面厚 56（轻微三分之四视角）
- 眼睛 30×80 竖向圆角条，两眼位置固定
- 四条腿，两只短臂，下垂外展 26°
- 光源在左上，阴影为右下侧赛璐璐平涂，描边 #2E2320 5px

## 局部修改方式
在 `looks.py` 找到对应类，改颜色常量或路径坐标，再运行 `render.py` 加该编号，最后运行 `overview.py`。
