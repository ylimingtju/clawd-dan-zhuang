## 转场：14 个小事件

每个转场都借用前后两首歌里的一个元素做道具，用一个有因果关系的小事件把同一个 Clawd 送进下一个世界，换装和换画风发生在这个事件里。画面里始终只有一个 Clawd。道具按所在世界的画风绘制：在 Riso 世界里是网点印刷的水管，在像素世界里是像素水管，在油画里是厚涂的门。转场第一帧接上一首最后一帧，最后一帧接下一首第一帧。

## 运行、修改与重新渲染

依赖：Python 3（numpy、opencv-python、scipy、Pillow）、`resvg-py`（SVG 光栅化）、`imageio-ffmpeg`（自带 ffmpeg）。安装命令：`pip install resvg-py imageio-ffmpeg`。

在 `源文件/` 目录下运行：

```bash
python3 render.py clip 01            # 重渲染某一段 → ../01_珠玉.mp4（可写 01,05,09）
python3 render.py clip all           # 全部 13 段 + 片头片尾（带余量）
python3 render.py work 00,14         # 片头片尾的带余量工作版（正片转场需要，存入 源文件/cache）
python3 render.py deliver_bookends   # 片头片尾成品（只含核心时长）
python3 render.py trans all          # 渲染 14 个转场 → ../转场/（可写 3,7 只渲染部分；需先运行 render.py work 00,14）
python3 render.py tstills 3 0.2,0.5,0.8   # 某个转场在指定进度的检查帧 → 源文件/检查/
python3 film.py                      # 拼接完整正片：核心段与转场首尾相接（需要 cache 中的片头片尾工作版）
python3 verify.py                    # 验收报告 + 关键帧总览 + 无标签画风检查图
python3 render.py stills 09 0.5,1.2,2.4   # 单段指定时刻的检查拼图 → 源文件/检查/
```

主要文件：

- `clawd.py`、`looks.py`：角色几何与 13 套服装，复制自第一轮审核源码，设计未改。视频版加入了姿势状态和渲染模式（完整 / 色块 / 色块加阴影 / 线条蒙版）。
- `engine.py`：姿势绑定、关键帧缓动、SVG→位图、噪声纹理、H.264 编码。
- `fx.py`：各画风的重绘器，包括体积光照、毛笔线、晕染、网点分色、撕纸、霓虹、木刻、逐笔油画、玻璃、色粉、擦笔水彩、蜡笔。
- `s01_珠玉.py` … `s13_有趣.py`：每段一个文件，`pose(t)` 是动作关键帧，`frame(t)` 是画面合成，文件开头的注释写明意象与画法。
- `intro.py`、`outro.py`、`titles.py`：片头片尾与共用标题（标题文字在 `titles.py` 的 `text_layer()` 中修改）。
- `trans.py`：14 个转场，每个是一个 `t_*` 事件函数（姿势、道具、遮罩都在里面）；文件末尾的 `TRANS` 表列出顺序、时长和名称。
- `film.py`：按顺序把各段核心部分和转场首尾相接。

改动作：编辑对应场景的 `pose()` 关键帧（时间、数值），重渲染该段，再运行 `film.py`。改画风参数：编辑对应场景的 `frame()` 或 `fx.py` 中的重绘器。改转场：编辑 `trans.py` 里的动作函数或 `TRANS` 表，运行 `render.py trans <编号>`，再运行 `film.py`。所有随机量都使用固定种子，重复渲染结果一致。

## 第三轮修改（按审核意见）

- 《君》：去掉眼睛周围的"黑眼圈"。原因是擦笔水彩的炭粉塑形把眼睛也当成一个色块，压暗了眼眶边缘。现在先塑形不含眼睛的角色，再把眼睛画回去，线条层也不再勾眼睛外圈。
- 转场：14 个转场全部重做，从"擦除 / 溶解"式改为镜头运动式，包括推拉、眼睛匹配、甩镜、旋转、剪影扩张、漏光、后拉，并加入动态模糊。
- 《思念是一种病》：删去红线，改为望着远岛灯笼隔海挥手，灯笼晃动亮起回应。
- 《舞娘》：去掉翻面"旋转"。本机没有 Blender 等三维工具，角色是二维绑定，做不出可信的 3D 转身，所以改成披风舞：蓄力、披风炸开、左右踏步并交替摆臂、深蹲收拢、起身高举。
- 重新导出了 `07`、`09`、`11` 和完整正片，并重新验收：规格不变，正片无黑帧，亮度突变只出现在转场窗口内。

## 已知限制

- 角色是二维绑定（身体、手臂、四腿、眼睛、头发、裙摆、帽子分别运动），不是三维模型，因此全片没有 3D 转身动作。翻滚和侧手翻是画面平面内的旋转。
- 全片 76.8 秒，比最初要求的 41–69 秒长约 7.8 秒，这是选择方案 A（每首歌展示时长不变）的结果。
- 转场里的碎玻璃下落和纸团揉皱是二维近似效果（碎片在画面内翻转下落，纸团是收缩加褶皱变形），不是三维物理模拟。
- 钻水管转场在她完全进入水管时直接切换世界，属于有意的硬切。
- 转场过程中定格类画风（05 撕纸、03 Riso 等）的一拍二、一拍三节奏没有保留，转场统一是 30fps 连续动作。
- 09 的照片里看不到黑色长手套，按"以照片为准"未画，与第一轮审核图一致。视频版的手臂改画在披风前面，以便举臂时可见。
- 05 撕纸为 10 fps 定格，每张画面有 ±1 像素的手作偏移；13 蜡笔每 4 帧换一次笔迹。这两处属于有意的风格化抖动，幅度很小。
- 08 油画为一拍二（15 fps），背景笔触固定在画面上，角色身上的笔触随角色移动，所以角色移动时边缘会有轻微的笔触变化。
